# Drafts

Use this directory for unpublished post ideas and rough outlines.

Draft file names do not need dates. When a draft is ready to publish, move it to
`_posts/` and rename it with the `YYYY-MM-DD-title.md` format.

Publishing boundary:

- Maintenance edits, typo fixes, metadata cleanup, and CI fixes can be prepared automatically.
- New posts, resume changes, personal positioning changes, and deletions require explicit review before publishing.
- Family details, private contact information, company-sensitive details, and non-public system details should stay out of the published site.
